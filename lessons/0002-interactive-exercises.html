Coding Practice Lab: Two Pointers Foundations

Exercises 4 Hands-On Coding Challenges Lessons 1 & 2
Prefer writing code in your local editor?
These exact challenges are in the exercises/ directory with Node test suites! Run npm run test:1, npm run test:2, etc., or write and test right here in the browser.

Exercise 1: Pair with Target Sum

Given a sorted array nums and an integer target, return the indices [left, right] of the two numbers that sum up to target. If no such pair exists, return [-1, -1].

Constraints & Target Complexity:
Time: $O(N)$ • Auxiliary Space: $O(1)$ • Converging Two Pointers
Terminal: npm run test:1
Click "Run Browser Tests" to execute.

Exercise 2: Squaring a Sorted Array

Given an integer array nums sorted in non-decreasing order, return an array of the squares of each number sorted in non-decreasing order.

Constraints & Target Complexity:
Time: $O(N)$ • Auxiliary Space: $O(N)$ output • Fill from largest squares backward
Terminal: npm run test:2
Click "Run Browser Tests" to execute.

Exercise 3: Valid Palindrome

Given a string s, return true if it is a palindrome after converting uppercase to lowercase and removing all non-alphanumeric characters.

Constraints & Target Complexity:
Time: $O(N)$ • Auxiliary Space: $O(1)$ • In-place two pointers skipping invalid chars
Terminal: npm run test:3
Click "Run Browser Tests" to execute.

Exercise 4: Remove Duplicates from Sorted Array

Given an integer array nums sorted in non-decreasing order, remove duplicates in-place such that each unique element appears once. Return the number of unique elements k.

Constraints & Target Complexity:
Time: $O(N)$ • Auxiliary Space: $O(1)$ • Fast & Slow Two Pointers
Terminal: npm run test:4
Click "Run Browser Tests" to execute.
