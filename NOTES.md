# Workspace Notes

## User Preferences
*   **Language:** JavaScript / TypeScript (ES6+)
*   **Starting Level:** Beginner (Start with fundamentals, explain indices, and progress carefully)
*   **Target Timeline:** Short-term Interview Prep (1-3 months)
*   **Topic:** Master DSA Patterns in full depth and an easy manner, progressing one pattern at a time.
*   **Gatekeeping Rule:** Move to the next pattern ONLY when the user is confident in solving "Hard" questions of the current pattern.
*   **Pedagogical Style:** Step-by-step visual explanations, interactive quizzes, direct code execution, and scaffolded progressive difficulty (Easy -> Medium -> Hard).

## Course Roadmap (Tentative Outline)
1.  **Two Pointers & Sliding Window** (Linear structures)
2.  **Fast & Slow Pointers** (Cycle detection / Midpoints)
3.  **Merge Intervals** (Overlapping intervals)
4.  **Cyclic Sort** (Numbers in a given range)
5.  **In-place Reversal of a Linked List**
6.  **Tree Breadth First Search (BFS)**
7.  **Tree Depth First Search (DFS)**
8.  **Two Heaps** (Dynamic medians / priority queues)
9.  **Subsets** (Permutations & combinations)
10. **Modified Binary Search** (Sorted search variations)
11. **Top 'K' Elements** (Heaps)
12. **K-way Merge** (Heaps / pointers)
13. **0/1 Knapsack / Dynamic Programming**
14. **Topological Sort** (Graphs)
15. **Trie (Prefix Tree)**
16. **Segment Tree & Fenwick Tree** (Advanced range queries)
