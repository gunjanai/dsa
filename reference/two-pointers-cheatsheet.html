Reference Sheet: Two Pointers Pattern

Reference Card Compressed Knowledge Target: JavaScript / TypeScript

1. Diagnostic Trigger: When to Use Two Pointers

Identify the pattern when:
  1. The input array or string is sorted (or sorting it costs $O(N \log N)$ which is cheaper than brute force $O(N^2)$ / $O(N^3)$).
  2. You are asked to find a pair, triplet, or subarray that meets a target sum or constraint.
  3. You need to perform an in-place modification (e.g. remove duplicates, reverse, partition) with $O(1)$ extra memory.
  4. Comparing characters from outer boundaries inward (e.g. palindrome checks).

2. The Three Pointer Archetypes

Variant Starting Positions Movement Rule Canonical Problems
Converging left = 0, right = n - 1 Pointers move towards each other until left >= right Pair with Target Sum, 3Sum, Valid Palindrome, Container With Most Water
Fast & Slow slow = 0, fast = 0 Both move forward; fast scouts elements, slow writes or marks cycle Remove Duplicates, Move Zeroes, Linked List Cycle
Opposite / Expanding left = center, right = center Pointers expand outward from center Longest Palindromic Substring

3. Code Templates (TypeScript / JavaScript)

Archetype A: Converging Pointers (Pair Search)

function pairWithTargetSum(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left < right) {
    const currentSum = arr[left] + arr[right];
    if (currentSum === target) {
      return [left, right];
    } else if (currentSum < target) {
      left++;  // Need larger sum
    } else {
      right--; // Need smaller sum
    }
  }
  return [-1, -1];
}

Archetype B: Fast & Slow (In-Place Compaction)

function removeDuplicates(nums) {
  if (nums.length === 0) return 0;
  let slow = 0;

  for (let fast = 1; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }
  return slow + 1; // Length of unique elements
}

Archetype C: Triplet Search with Duplicate Skipping (3Sum)

function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const triplets = [];

  for (let i = 0; i < nums.length - 2; i++) {
    // Early exit: if smallest element > 0, sum cannot be 0
    if (nums[i] > 0) break;
    // Skip duplicate fixed element
    if (i > 0 && nums[i] === nums[i - 1]) continue;

    let left = i + 1;
    let right = nums.length - 1;

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right];
      if (sum === 0) {
        triplets.push([nums[i], nums[left], nums[right]]);
        // Skip duplicate left and right values
        while (left < right && nums[left] === nums[left + 1]) left++;
        while (left < right && nums[right] === nums[right - 1]) right--;
        left++;
        right--;
      } else if (sum < 0) {
        left++;
      } else {
        right--;
      }
    }
  }
  return triplets;
}

4. Common Pitfalls & Traps

  • Forgetting to Sort: Two pointers relying on monotonic behavior will fail silently on unsorted input. Always confirm if sorting is allowed and how it impacts overall complexity.
  • Infinite Loops on Duplicates: When advancing past duplicates (while (nums[left] === nums[left + 1]) left++), remember to execute the final left++ to land on the new distinct element!
  • Strict Inequality vs Leeway: Know whether your loop boundary requires left < right (pairs must be distinct indices) or left <= right (pointers may inspect the exact same midpoint or single remaining element).
