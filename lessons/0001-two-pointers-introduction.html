Lesson 1: Mastering the Two Pointers Pattern

Difficulty: Easy Topic: Array / Linear Search Optimization Language: JavaScript / TypeScript

The Core Concept: Converging Pointers

Imagine you are given a sorted array of integers and asked to find two numbers that add up to a specific target sum.

Problem: Pair with Target Sum
Input: nums = [1, 2, 4, 6, 8, 10, 13], target = 14
Output: [2, 5] (Indices of numbers 4 and 10 which sum to 14)

Why not check every pair? (The Brute Force Approach)

If we use a nested loop to check every possible pair of elements, we will perform $O(N^2)$ operations. For an array of size $10^5$, this would require $10^{10}$ comparisons, which will crash or timeout in an interview.

But wait! The array is sorted. This sorted property is a massive hint that we can do much better.

How Two Pointers Optimizes This

We place one pointer (left) at the very beginning (index 0) and another pointer (right) at the very end (index nums.length - 1).

At each step, we calculate the sum of the elements at these two pointers: currentSum = nums[left] + nums[right].
  • If currentSum === target: We found the pair! Return their indices.
  • If currentSum < target: The sum is too small. Since the array is sorted, the only way to increase the sum is to move the left pointer to the right (left++).
  • If currentSum > target: The sum is too large. The only way to decrease the sum is to move the right pointer to the left (right--).

Because we move at least one pointer in each step, we traverse the array at most once, achieving a lightning-fast $O(N)$ Time Complexity and $O(1)$ Space Complexity.

The JavaScript Implementation

Here is the clean, idiomatic ES6 JavaScript implementation of the Two Pointers approach: 

/**
 * Finds two indices in a sorted array that sum up to target.
 * Time Complexity: O(N)
 * Space Complexity: O(1)
 * @param {number[]} nums
 * @param {number} target
 * @return {number[]} [leftIndex, rightIndex] or []
 */
function pairWithTargetSum(nums, target) {
    let left = 0;
    let right = nums.length - 1;

    while (left < right) {
        const currentSum = nums[left] + nums[right];

        if (currentSum === target) {
            return [left, right]; // Found the pair!
        } else if (currentSum < target) {
            left++; // Need a larger sum
        } else {
            right--; // Need a smaller sum
        }
    }

    return []; // No pair found
}

1. Why does the Two Pointers pattern require the array to be sorted for this problem?
A) Because the while-loop condition 'left < right' only works on sorted elements.
B) Because sorting allows us to confidently know whether moving a pointer increases or decreases the sum.
C) Because JavaScript arrays must be sorted before performing any operations on them.
2. What is the Space Complexity of the Two Pointers solution?
A) O(N) because we might have to traverse all N elements in the array.
B) O(log N) because the pointers converge in a binary search-like fashion.
C) O(1) because we only use a constant amount of extra space (two pointer variables).
