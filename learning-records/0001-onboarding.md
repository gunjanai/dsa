# Established Learner Profile and Goals

The user's preferred language is JavaScript/TypeScript, starting as a Beginner with a short-term interview prep timeline (1-3 months). All course exercises, visualizers, and code sheets will use JS/TS, starting with the foundational "Two Pointers" pattern to build strong array indexing fundamentals.

## Evidence
Established during onboarding session:
- **Language:** JavaScript / TypeScript
- **Starting Level:** Beginner (needs basic structure conceptualization alongside pattern teaching)
- **Timeline:** Short-term interview prep (1-3 months)

## Implications
- Code examples must avoid overly complex TypeScript gymnastics; prefer clear, typed, idiomatic ES6 JS/TS.
- Explain foundational array indices, pointers, and memory layout before diving into complex loops.
- Start with the "Two Pointers" pattern (converging pointers) which is the most intuitive gateway to algorithmic reasoning.
