To master the Two Pointers Pattern, you need to see how it bends and adapts to different problems. Some problems use pointers moving towards each other (converging), while others use two pointers moving in the same direction at different speeds (fast/slow runner).

Simulation 1: Squaring a Sorted Array

The Problem: Given an integer array sorted in ascending order, return an array of the squares of each number sorted in ascending order.

Example Input: nums = [-4, -1, 0, 3, 10]
Expected Output: [0, 1, 9, 16, 100]
The Trick: Negative numbers square to positive. The largest squares must live at either the extreme left or extreme right. We can build our output backwards!

The Algorithm Explained

Compare Math.abs(nums[left]) with Math.abs(nums[right]). Whichever absolute value is larger, square it and write it to the end of your new array, then move that pointer inwards. Repeat until the input pointers meet. 

function sortedSquares(nums) {
    const n = nums.length;
    const result = new Array(n);
    let left = 0;
    let right = n - 1;
    let writeIdx = n - 1;

    while (left <= right) {
        const leftVal = Math.abs(nums[left]);
        const rightVal = Math.abs(nums[right]);

        if (leftVal > rightVal) {
            result[writeIdx] = leftVal * leftVal;
            left++;
        } else {
            result[writeIdx] = rightVal * rightVal;
            right--;
        }
        writeIdx--;
    }
    return result;
}

Simulation 2: Valid Palindrome

The Problem: Check if a string is a palindrome, ignoring non-alphanumeric characters and casing.

Example Input: "r a c e c a r"
Expected Output: true
The Trick: Start pointers at both ends. Compare chars. If equal, shift both inwards. If we find any mismatch, we exit immediately with false.

The Algorithm Explained

This is the most straightforward Two Pointers application. By comparing characters from both ends converging to the middle, we get a simple $O(N)$ solution with $O(1)$ extra space. 

function isPalindrome(s) {
    let left = 0;
    let right = s.length - 1;

    while (left < right) {
        if (s[left] !== s[right]) {
            return false; // Mismatch found
        }
        left++;
        right--;
    }
    return true; // All pairs matched
}

Simulation 3: Remove Duplicates from Sorted Array

The Problem: Given a sorted array, remove duplicates in-place such that each unique element appears only once. Return the length of the deduplicated prefix.

Example Input: [2, 3, 3, 3, 6, 9]
Expected Output Length: 4 (Array becomes [2, 3, 6, 9, _, _])
The Trick: This uses the Fast & Slow Two Pointers sub-pattern. The fast pointer scans the array, while the slow pointer marks the next slot to write a unique number.

The Algorithm Explained

The fast pointer iterates through the array. If the number at fast is different from the number before slow, it means we have found a new unique element. We copy it to index slow and increment slow. 

function removeDuplicates(nums) {
    if (nums.length === 0) return 0;
    
    let slow = 1; // Position of the next unique element

    for (let fast = 1; fast < nums.length; fast++) {
        // Compare with the last unique element placed
        if (nums[fast] !== nums[slow - 1]) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow; // Length of unique prefix
}
