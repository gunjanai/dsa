## How to Work Through the Exercises

1. Open the exercise file in your editor (e.g. `exercises/01-pair-with-target-sum.js`).
2. Read the docstring specifications, examples, and algorithmic hints.
3. Replace the `TODO` with your implementation.
4. Run the targeted test command in your terminal:
   ```bash
   npm run test:1
   ```
5. When all tests pass, move to the next exercise!
6. To run all exercise tests together:
   ```bash
   npm test
   ```
