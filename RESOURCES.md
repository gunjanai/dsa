# DSA Patterns Resources

Knowledge for our lessons is drawn from primary sources and top-tier pedagogical experts. Wisdom is acquired by testing these skills in real-world environments and communities.

## Knowledge

- [DesignGurus.io - Grokking the Coding Interview](https://www.designgurus.io/course/grokking-the-coding-interview)
  The pioneer of the pattern-based approach to DSA. Outstanding for understanding how complex coding questions map down to 15-20 core patterns.
- [NeetCode.io](https://neetcode.io)
  A legendary catalog of problem solutions organized into clean maps (NeetCode 150). Excellent for structured visual explainers and clean Python code implementations.
- [Tech Interview Handbook](https://www.techinterviewhandbook.org)
  An open-source, highly curated handbook with direct study plans, key cheat sheets, and practical implementation tips.
- [LeetCode Patterns by Sean Prasad](https://seanprashad.com/leetcode-patterns/)
  A superb curated list of LeetCode questions categorized by pattern and difficulty level, used globally by software engineers.
- [Book: _Introduction to Algorithms_ (CLRS) by Cormen, Leiserson, Rivest, & Stein](https://mitpress.mit.edu/9780262046304/introduction-to-algorithms/)
  The definitive, mathematically rigorous academic text on algorithms. Reach for this to master exact time/space complexity proofs and formal verification.
- [Book: _The Algorithm Design Manual_ by Steven S. Skiena](https://www.algorist.com)
  Practical design text focusing on real-world engineering trade-offs and selecting the right structures.

## Wisdom (Communities)

- [r/leetcode](https://reddit.com/r/leetcode)
  Active community discussing problem-solving techniques, pattern identification, and technical interview reviews.
- [LeetCode Discuss Section](https://leetcode.com/discuss/)
  High-signal community solutions and optimization breakdowns written by practitioners.
